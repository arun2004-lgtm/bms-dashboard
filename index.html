How It Works

  1. The ESP32 connects to Wi-Fi and accumulates high-accuracy readings every second.
  2. Every 5 seconds, Core 0 transmits a live snapshot to your Firebase Realtime Database.
  3. This web app listens in real-time via WebSocket and updates your screen with zero latency!
  4. You can bookmark this page or deploy it to GitHub Pages or Vercel to check your battery from anywhere in the world.

Connect Firebase Database

Enter your Firebase Realtime Database URL. It typically looks like:
https://your-project-id-default-rtdb.firebaseio.com

Make sure you also pasted this exact same URL into your ESP32's include/Cloud.h file as FIREBASE_RTDB_URL!
